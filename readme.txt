== Description ==
Smart Summary is a plugin that quickly summarizes your articles.

Helping readers better browse your content and improving user experience. 

Suitable for site owners and content creators.

== Short Description ==
Automatically generate a summary of your articles for readers to browse.

== Installation ==
1. Download the plugin zip file.
2. Go to the "Plugins" page in your WordPress admin dashboard and click "Add New." 
3. Upload the plugin zip file and click "Install."
4. Activate the plugin.
5. A summary of your article will appear on the post view page, allowing your readers to see the article summary.

== Frequently Asked Questions ==
= Does the plugin support multiple languages? =
Yes, the plugin supports multiple languages. You can add translation files to the `/languages` directory as needed.

= Is the plugin compatible with all themes? =
The plugin has been tested and is compatible with most popular themes. If you encounter any issues, please contact us through the support channel.
